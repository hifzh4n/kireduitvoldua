# 03: Editorial UI Shell and Summary Header

**What to build:**
Create the calm, natural, editorial application shell (inspired by classic accounting ledgers and high-density productivity tools, no AI slop). Includes top summary metrics bar (Total Spent This Month in RM, Net Owed to Me, Net I Owe), month selector, and tab navigation between "Expenses", "Who Owes Me", and "Who I Owe".

**Blocked by:** 02: Supabase Schema and Storage Repository Layer

**Status:** resolved

- [x] Calm editorial design with warm bone/slate/zinc surfaces, sharp high-contrast typography, and monospace tabular numerals
- [x] Month/year picker with previous/next month navigation
- [x] Responsive tab switcher between Expenses, Who Owes Me, Who I Owe, and Category Budgets
