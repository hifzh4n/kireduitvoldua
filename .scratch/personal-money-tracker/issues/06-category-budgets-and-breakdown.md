# 06: Category Budget and Monthly Spending Summary

**What to build:**
A visual category budget and spending breakdown view. Shows monthly RM spending per category, percentage of budget spent with subtle progress indicators, and an inline editor to set or adjust category monthly RM budget targets.

**Blocked by:** 04: Expenses Vertical Slice

**Status:** resolved

- [x] Category breakdown card showing total spent per category in the current month
- [x] Budget progress bars (e.g. `RM 340 / RM 500 spent (68%)`) with muted visual indicators
- [x] Category manager dialog allowing user to set/update monthly budget limits in RM
- [x] Ability to add custom categories or edit existing category names
