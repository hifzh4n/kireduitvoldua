# 04: Expenses Vertical Slice

**What to build:**
Complete expense management slice: viewing expenses for the selected month, filtering by category, search by note, deleting an expense, and a fast Quick Add Expense modal with date, category picker (prefilled with Malaysian defaults), RM amount input, and notes.

**Blocked by:** 03: Editorial UI Shell and Summary Header

**Status:** resolved

- [x] High-density expense list grouped by date with category badge and formatted RM amount
- [x] Category filter dropdown and instant keyword search
- [x] Quick Add Expense dialog with autofocus, auto-formatting of RM, date default to today, and keyboard `Enter` to submit
- [x] 1-click delete with confirmation
- [x] Instant reactivity: summary header and category totals update immediately upon adding or deleting
